## 🚀 시작하기

### 필수 요구사항

- Node.js 18.x 이상
- npm 또는 yarn
- Docker (선택사항)

### 설치 및 실행

#### pnpm 설치를 먼저 해주세요!

```bash
# 저장소 클론
git clone https://github.com/your-org/web16-boostcamp.git
cd web16-boostcamp

# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm dev
```
