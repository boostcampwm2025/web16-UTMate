## 📌 프로젝트 소개

**UTMate**는 웹 서비스의 사용자 테스트를 효율적으로 진행할 수 있도록 돕는 통합 플랫폼입니다.

### 주요 기능

- 🎯 SDK를 통한 자동 이벤트 수집
- 📊 실시간 사용자 행동 분석
- 🎬 세션 리플레이 기능
- 📝 테스트 시나리오 관리

## 🚀 시작하기

### 필수 요구사항

- Node.js 18.x 이상
- npm 또는 yarn
- Docker (선택사항)

### 설치 및 실행

#### pnpm 설치를 먼저 해주세요!

```bash
# 저장소 클론
git clone https://github.com/your-org/web16-boostcamp.git
cd web16-boostcamp

# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm dev
```
